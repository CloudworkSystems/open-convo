# Lucide folder icon source

Selected SVG paths are copied from [Lucide](https://github.com/lucide-icons/lucide/tree/500620a2e8123f8d1db191538886dc0c223f69a9/icons), commit `500620a2e8123f8d1db191538886dc0c223f69a9`, under its [ISC and applicable MIT license](LICENSE). The original default Desk folder icon is retained. No external icon request or dependency is needed at runtime.

Included icons: book-open, briefcase, lightbulb, heart, star, house. SVG path geometry is unchanged; stroke width follows the Desk interface.
