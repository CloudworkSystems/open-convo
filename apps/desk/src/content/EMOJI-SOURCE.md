# Emoji set source

`emoji.json` holds every standard emoji (1,914, Emoji 17.0, without skin-tone
variants) with its Unicode name, in Unicode's nine groups. It was generated by
`scripts/generate-emoji-data.mjs` from `data-by-group.json` in the npm package
[unicode-emoji-json](https://github.com/muan/unicode-emoji-json) 0.9.0, under
its MIT license ([emoji-LICENSE](emoji-LICENSE)). The package is not a
dependency and nothing is fetched at runtime; the Desk loads this file on its
own the first time the owner opens "More emoji". The pictures come from the
system's emoji font, so on the Mac they are Apple's emoji.
