# Open Convo

Open Convo is the open-source core of True Convo. This repo is where True Convo
is built: the Desk, the Mac app with dictation and the heads-up display, and the
clarity tools.

## Status

- **October 12, 2026:** Repo set up as the new home for product work. True Convo
  is frozen and serves as the private reference and parts library.
- No code has moved yet. The proposed order is in [PLAN.md](PLAN.md).
