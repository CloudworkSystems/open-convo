True Convo API

A small, read-only API that answers questions about True Convo from public text we write and review.

Beta. Answers can change as True Convo develops.

Base address: https://api.trueconvo.com. It needs no key and no account, holds no personal data and writes no logs of its own. The full description is in openapi.json (OpenAPI 3.1).

REST

Every answer is JSON.

RequestWhat it returnsParameters
GET /v1/aboutWhat True Convo is.None
GET /v1/featuresFeatures with their real status.None
GET /v1/faqFrequently asked questions.q (optional string, up to 200 characters): Words that every returned entry must contain (case-insensitive).
GET /v1/privacyPrivacy promises.None
GET /v1/statusDevelopment status.None
GET /v1/updatesDated update notes, newest first.None
GET /openapi.jsonThis OpenAPI description.None

MCP

POST /mcp is a Model Context Protocol server over Streamable HTTP. It is stateless: each request carries one JSON-RPC message and gets one JSON answer. It offers the same answers as read-only tools:

ToolWhat it returnsArguments
aboutWhat True Convo is, who makes it, and whether it is available.None
featuresTrue Convo features, each labeled available, in development or planned.None
faqFrequently asked questions about True Convo, optionally filtered by words.q (optional string, up to 200 characters): Words that every returned entry must contain.
privacyTrue Convo's privacy promises and a link to its privacy policy.None
statusHow far along True Convo development is.None
updatesDated update notes about True Convo, newest first.None

Requests over 16 KB are refused.

Limits

Each address can send up to 10 requests in 10 seconds. Past that, it is blocked for 10 seconds. The service runs on a free plan with a daily limit, so it may stop answering for the rest of a day if that limit is reached.
