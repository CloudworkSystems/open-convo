True Convo API

A small, read-only API that answers questions about True Convo from public text we write and review.

Beta. Answers can change as True Convo develops.

Base address: https://api.trueconvo.com. It needs no key and no account, holds no personal data and writes no logs of its own. The full description is in openapi.json (OpenAPI 3.1).

REST

Every path answers GET with JSON.

PathWhat it returns
/v1/aboutWhat True Convo is, who makes it, and whether it is available.
/v1/featuresThe features, each labeled available, in development or planned.
/v1/faqFrequently asked questions. Add ?q= and some words (up to 200 characters) to get only the entries that contain every word.
/v1/privacyOur privacy promises, with a link to the privacy policy.
/v1/statusHow far along development is.
/v1/updatesDated update notes, newest first.
/openapi.jsonThe OpenAPI description of this API.

MCP

POST /mcp is a Model Context Protocol server over Streamable HTTP. It is stateless: each request carries one JSON-RPC message and gets one JSON answer. It offers the same answers as read-only tools:

ToolArguments
aboutNone
featuresNone
faqOptional q: words every returned entry must contain
privacyNone
statusNone
updatesNone

Requests over 16 KB are refused.

Limits

Each address can send up to 10 requests in 10 seconds. Past that, it is blocked for 10 seconds. The service runs on a free plan with a daily limit, so it may stop answering for the rest of a day if that limit is reached.
