# Public Website: Folder Rules

These add to the repo's top [AGENTS.md](../AGENTS.md); they never replace or
loosen it.

- Anything here that merges to `main` goes live on trueconvo.com through the
  `pages` workflow, as do `brand/tokens.css` and `brand/fonts/`. Each such
  pull request is a public publication, so it needs the owner's yes in a
  Claude thread, quoted with its date in the pull request, before auto-merge
  goes on.
- Public contact details the owner chose to publish are allowed. Nothing
  else personal, private or unreleased goes here.
- No trackers, analytics or third-party scripts unless a merged plan allows
  them. A new outside host trips the risk hold.
