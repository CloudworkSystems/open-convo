# Security

Open Convo is a public repository and an early-stage, local-first app. If
you find a security problem, thank you for telling us privately first.

## Reporting a vulnerability

- Use GitHub's private reporting: the **Security** tab of this repository,
  then **Report a vulnerability**.
- If that isn't available to you, email trueconvo2@gmail.com with
  "Security" in the subject.

Please don't open a public issue or pull request for a vulnerability until
it's fixed. Include what you found, how to reproduce it, and what it could
let someone do. We'll reply as soon as we can and say what happens next.

## What's in scope

The code in this repository: the Mac app, the Desk, the packages, the
GitHub workflows and their scripts, and the public site in `site/`.
How the project approaches security is in
[docs/plans/security.md](docs/plans/security.md).
