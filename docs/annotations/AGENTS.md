# Annotation Rounds: Folder Rules

These add to the repo's top [AGENTS.md](../../AGENTS.md); they never replace
or loosen it.

- Only Codex writes here, when the owner says "save this round". One file per
  named session, `<session-name>.md`, with its screenshots beside it as
  `<session-name>-01.png`, `-02.png` and so on.
- Format and the pull request steps: [docs/agent-process.md](../agent-process.md)
  (Review Loop, "save this round") and
  [docs/plans/annotation-rounds.md](../plans/annotation-rounds.md).
- A round's pull request changes only these files and no code.
- Builders read a round here and don't edit it. If an item is unclear, ask in
  the build's pull request.
